## 🧠 What I Learned

This project was built while i was teaching myself JavaScript. The key concepts I practised:

- **DOM Manipulation** — selecting and updating elements dynamically, toggling classes, updating text content in real time
- **Event Listeners** — handling clicks, form submissions, and scroll events across multiple elements
- **IntersectionObserver** — triggering scroll reveal animations when elements enter the viewport, with a stagger effect
- **Form Validation** — validating email input with regex and giving users feedback through a custom toast notification system


No installs. No build step.
